--------------------------

====================================

			|		  	                                    |         | 
			|		                                UserDetailsService   PasswordEncoer

Explanation
--------------------
-->After user enter username & pwd and trigger the  request
-->It comes to AuthenticationFilter 
-->AuthenticationFilter forwarded to Authentication
-->Authentication takes that username & pwd values it converts or it forms a object
-->and it returns to AuthenticationFilter ,and AuthenticationFilter passess  that object to AuthenticationManager
-->AuthenticationManager passes that details or object to the AuthenticationProvider
-->AuthenticationProvider uses  UserDetailsService & PasswordEncoer to authenticate
-->and returns authentication result to AuthenticationFilter 
-->if the result (provided details ) correct then those detials set to   Security Context





1)AuthenticationFilter 
------------------------
a filter that intercepts and perfroms authentication of a particular request by delegating it to the authentication manager.if the authentication
is successfull,then authentication details set to the SecurityContext


2)Authentication
--------------------
Using  the supllied values from the user like username and password,the authentication will be formed which will be given as an input to 
the AuthenticationManager Interface

3)AuthenticationManager 
-------------------------------
-->Once receive the requestfrom filter it delegates the validating the user details to the AuthenticationProvider.

4)AuthenticationProvider
------------------------------
-->It has the all the logic to validate the user details  Using  UserDetailsService & PasswordEncoer



For Security Feature In our Application we need to add Spring security dependency in our pom.xml
---------------------------------------------------------------------------------------------------------
    <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-security</artifactId>
    </dependency>



-->after added this dependency our application got secured

package com.studentCrud.securityConfig;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.core.userdetails.User;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.provisioning.InMemoryUserDetailsManager;
import org.springframework.security.web.SecurityFilterChain;
import static org.springframework.security.config.Customizer.withDefaults;

//for customized spring security instead of default security we here write the code 

@Configuration
public class SecurityConfig 
{
//this PasswordEncoder-->the AuthenicationProvider uses PasswordEncoder and UserDetailsService to authenticate
	@Bean
	public PasswordEncoder pwdEncoder() {
		return new BCryptPasswordEncoder();
		
	}

	
//this UserDetailsService-->the AuthenicationProvider uses PasswordEncoder and UserDetailsService to authenticate	
	@Bean
	public UserDetailsService userDetailsService()
	{
		UserDetails adminUser  = User.withUsername("admin")
				.password(pwdEncoder().encode("admin"))
				.roles("ADMIN")
				.build();
		
		
		UserDetails userUser  = User.withUsername("user")
				.password(pwdEncoder().encode("user"))
				.roles("USER")
				.build();
		
		
		return new InMemoryUserDetailsManager(userUser,adminUser);
				
		
	}
